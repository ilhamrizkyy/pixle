# Product

## Users

- **Developers and designers who need pixel icons.** They land on the gallery,
  search or filter, set color, shape and size, and copy or download an icon.
  No sign-in. Some grab files from `icons/` on GitHub instead.
- **Contributors** who add icons by pull request (CONTRIBUTING.md).
- **The owner (Ilham, credited as lovvfat)**, the only person who uses the
  composer.

## Purpose

Pixle is an open-source pixel icon set where every icon is drawn cell by cell
on the same 11 by 11 grid. Success is a visitor leaving with an icon in their
project, and the set reading as one family.

## Brand

- Name: **Pixle**. MIT licensed.
- Arcade world: a full-screen CRT hero (Press Start 2P name, VT323 text, neon
  on near-black). The gallery below it is where the work happens.
- Page copy is American English, active voice, no em dashes.
- No testimonials, download counts or numbers that don't exist. The icon count
  is real and may be shown.

## Principles

1. **The icons are the stars.** Chrome frames the set; it never out-details it.
2. **What you see is what you copy.** Display settings travel into exports.
3. **Works when cloned.** Nothing depends on someone else's database.
4. **Simple code that works well.**
